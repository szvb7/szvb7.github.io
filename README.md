## Структура сајта

- `index.html` — почетна страна
- `o-zgradi.html` — информације о згради и стамбеној заједници
- `obavestenja.html` — обавештења за станаре
- `dokumenta.html` — званична документа (решења, записници, извештаји)
- `finansije.html` — месечни приказ прихода и расхода
- `kontakt.html` — контакт подаци, хитне службе, контакт форма
- `style.css` — заједнички стил за све странице
- `dokumenti/` — PDF фајлови докумената

## Како ажурирати сајт

### Додавање новог обавештења

1. Отворите `obavestenja.html` у текстуалном едитору (Notepad, VS Code, Sublime)
2. Пронађите коментар `НОВО ОБАВЕШТЕЊЕ` (при крају фајла)
3. Копирајте блок `<article class="obavestenje">...</article>`
4. Налепите га изнад претходног обавештења (најновије иде на врх)
5. Замените наслов, датум и текст
6. Сачувајте фајл и отпремите на GitHub/Netlify

### Додавање новог документа

1. Ставите PDF у фасциклу `dokumenti/`
2. Отворите `dokumenta.html`
3. У одговарајућу секцију додајте нови `<li>` блок:
   ```html
   <li>
       <a href="dokumenti/novi-dokument.pdf" target="_blank">Назив документа</a>
       <span class="doc-meta">PDF</span>
   </li>
